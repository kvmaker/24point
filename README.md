# 24 点求解器

给出 4 张牌，用 +、−、×、÷ 凑出 24。

## 使用方法

直接在文件管理器中双击 `index.html` 打开，无需安装任何依赖，无需联网。

## 数字范围

每个输入框接受 **1–10** 的正整数，对应标准扑克牌的点数（A=1，2–10 取面值）。

## 分数中间结果开关

页面底部有「允许分数中间结果」复选框，默认**关闭**。

- **关闭**：中间步骤必须保持整数。例如 3 3 8 8 在整数模式下无解。
- **开启**：允许中间产生分数，最终结果仍须为 24。例如 3 3 8 8 在分数模式下有唯一解：
  `8 ÷ (3 - 8 ÷ 3)`
  （计算过程中 `8 ÷ 3` 是分数 8/3）

## 算法说明

求解器采用**递归两两合并**策略：

1. 把 4 个数看作 4 个有理数节点（分子/分母）。
2. 枚举任意两个节点的顺序与运算符（+、−、×、÷ 各两个方向），合并成一个新节点，得到 3 个节点的列表。
3. 递归到只剩 1 个节点时，检查其值是否等于 24/1。
4. 对所有满足条件的表达式，用**等价键（canonical key）**去重：  
   - 加减链按符号归一化后排序；乘除链按因子归一化后排序。  
   - 注意：分配律等价（如 `(a+b)×c` 与 `a×c+b×c`）**不**消除，因为它们的运算结构不同，都会显示。

## 页面自检

在浏览器地址栏访问：

```
index.html#selftest
```

（或 `http://localhost:<端口>/index.html#selftest`）

页面会在底部追加 7 行自检结果，每行以 `PASS` 或 `FAIL` 开头，覆盖整数/分数模式的边界用例。
