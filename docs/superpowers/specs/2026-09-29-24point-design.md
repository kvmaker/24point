# 24 点求解器设计

日期：2026-09-29
状态：待审阅

## 目标

输入 4 个数字，列出所有能通过四则运算得到 24 的算式。交付一个零依赖的单文件
Web 页面，双击即可在浏览器中使用。

## 交付物

| 文件 | 说明 |

| `index.html` | 求解器本体，内嵌 CSS + JS，无任何外部依赖或 CDN |

## 功能需求

- **FR1 输入**：4 个数字输入框，接受 1–10 的整数。提供 1–10 的数字快捷按钮，
  点击填入下一个空位。界面上不出现 J / Q / K 等牌面符号。
- **FR2 求解**：点击「求解」后计算并列出全部算式。
- **FR3 分数开关**：复选框「允许分数中间结果」，**默认关闭（整数模式）**。
  - 关闭：每步运算结果必须为整数，除法要求整除。
  - 打开：使用有理数精确运算（`{n, d}` 分数对 + 约分），除法仅需除数非零。
- **FR4 结果展示**：顶部显示解的条数；每条一行算式，使用 `×` `÷` 符号与仅在必要时
  添加的括号。排序规则：先按算式字符串长度升序，再按字典序，保证每次求解输出顺序
  稳定。无解时明确显示「这组数字无解」，而不是空白列表。
- **FR5 随机出题**：随机生成 4 个 1–10 的数字填入输入框。
- **FR6 自检**：访问 `index.html#selftest` 时运行内置断言并在页面输出结果，
  用于验证求解器与去重逻辑。

## 输入校验与边界

- 非整数、留空、超出 1–10 的输入：在按钮下方显示内联提示，不执行求解。
- 除数为 0：跳过该运算分支，不产生解。
- 允许负数中间结果（如 `3-8` 得到 -5 后可继续参与运算）。
- 不设结果条数上限；列表区域可滚动，条数已在 FR4 中展示。

## 算法

采用递归合并而非「全排列 × 运算符 × 括号形状」枚举，天然覆盖所有括号结构：

1. 状态为一组 `{value, expr}` 节点，初始为 4 个叶子节点。
2. 每步取两个节点 `a, b`（遍历所有 `i < j` 组合），生成候选新节点：
   - `a + b`、`a × b`（交换律，各只生成一次）
   - `a - b` 与 `b - a`（两种顺序都要）
   - `a ÷ b` 与 `b ÷ a`（两种顺序都要；整数模式下要求整除）
3. 用新节点替换 `a, b`，节点数 4 → 3 → 2 → 1。
4. 剩 1 个节点时，若其值为 24，记录该表达式树。

搜索空间上限约 7680 条路径，浏览器中毫秒级完成，无需剪枝或缓存。

整数模式下数值用 JS number 直接计算（结果恒为整数，无浮点误差风险）。
分数模式下用 `{n, d}` 分数对表示，每步运算后约分，比较时交叉相乘。

## 去重：规范化等价键

对每棵表达式树计算一个字符串键，同键视为同一解。核心思想是**把减法改写为
「加负数」、除法改写为「乘倒数」，再摊平同级链并排序**：

- `+` / `×` 节点：摊平同运算符的链，子项按键排序后输出。
  → 消除 `(a+b)+c` vs `a+(b+c)`、`a+b` vs `b+a`。
- `-` 节点：表示为加法链中的一项 `neg(b)`。
  → 消除 `a-b+c` vs `a+c-b`（移项）。
- `÷` 节点：表示为乘法链中的一项 `inv(b)`。
  → 消除 `a÷b×c` vs `a×c÷b`。
- 附加化简规则：`neg(neg(x)) = x`、`inv(inv(x)) = x`、`neg(a×b) = neg(a)×b`、
  `inv(a×b) = inv(a)×inv(b)`、`neg(a+b) = neg(a)+neg(b)`。
- 叶子节点用**数字的值**而非原始位置。
  → `3 3 8 8` 中两个 3 互换不产生新解。

**能消除**：交换律、结合律、移项与约分位置的重复。
**不消除**：分配律等价，如 `(a+b)×c` 与 `a×c+b×c` 会各显示一条。这属于代数
化简范畴，超出本工具范围，实际出现频率低。

## 自检断言（FR6）

- `3 3 8 8`：整数模式无解；分数模式有解且包含 `8÷(3-8÷3)`。
- `1 5 5 5`：整数模式无解；分数模式有解。
- `4 4 10 10`：两种模式均有解（`(10×10-4)÷4`）。
- `1 1 1 1`：两种模式均无解。
- `1 2 3 4`：结果中不存在两条互为交换律/结合律重复的算式。

## 范围之外

- 目标值固定为 24，不支持改成其他数字。
- 不支持幂、阶乘、开方等高级运算。
- 不做分配律等价的代数化简。
- 不引入构建工具、框架或任何外部依赖。
